Forks, English briefs, and where they fit.

Permissive upstreams only. The action refuses a fork when the license is missing or copyleft. Economic value means the work runs on a machine the person already has. Community value means the license stays attached. Disability support means the accessibility tree and a local voice come before a vendor screenshot. Everyday means a person who is not a lab can tell what ran.

Apache-2.0 · everyday, disability, economic

Shizuku

Upstream RikkaApps/Shizuku

Shizuku lets an ordinary Android app use ADB-level APIs through a small service the person starts themselves, instead of requiring root.

broccoli-rish is the transport. Shizuku is the privilege boundary. Keep them separate. The phone runs the command. A cloud agent only sends the text of the request.

Do not: Do not hide the Shizuku start step. Do not ship a private fork that drifts from upstream security fixes. Do not use the API to click through another app's purchase screen.

  • broccoli-rish — Keep lib/rish_run.sh as the only wrapper. Record the upstream Shizuku release it was tested against in the brief's commit, not in a screenshot.
  • broccoli-core — The kernel tick may call rish. It must not shell out to su. If Shizuku is not running, the tick returns a spoken and written 'not ready' instead of a fake success.
  • dectalk-live — Speak that 'not ready' locally. Do not send the failure text to a paid voice API.

Other agent stacks: Any agent runtime can use the same split. The agent emits a request. A local executor holding Shizuku permission runs it. The agent never receives a shell on the phone.

MIT · disability, everyday, community

nvgt-bridge

Upstream trypsynth/nvgt-bridge

A small Kotlin accessibility service that gives an audio game direct touch while TalkBack keeps menus, dialogs, and the keyboard.

Broccoli should observe the accessibility tree and leave TalkBack in charge of system UI. Grabbing the whole screen is how automation breaks a blind user's phone.

Do not: Do not disable TalkBack. Do not read notification text off the device to a remote model.

  • broccoli-core — Prefer accessibility-node actions (click a labeled node) over coordinates. If TalkBack is on, do not steal focus from it except for the node named in the request.
  • dectalk-live — DECtalk is an extra voice for app results. It is not a replacement for the system screen reader.
  • newsroom-desk — When a story is about background control of a phone, this bridge is the counter-example: the user can tell which layer has the gesture.

Other agent stacks: Expose two tools to the model: speak_result and activate_labeled_node. Do not expose a raw swipe-anywhere tool when a screen reader is on.

MIT · disability, community, everyday

A11y-Box-Android

Upstream rwapp/A11y-Box-Android

A small sample app of Android accessibility APIs: labels, focus, and the checks a developer is supposed to run.

A control is fair game for automation only when it has a name a person using a screen reader would also hear.

Do not: Do not treat an unlabeled button as acceptable because a vision model can guess it.

  • broccoli-core — Add an offline fixture, copied under its MIT license with the copyright kept, that the kernel uses in smoke tests: refuse to activate a node with an empty content description.
  • newsroom-desk — Cite the sample when explaining why a banking or chat app that hides the label fails both disabled users and any honest automation.

Other agent stacks: Put the accessibility tree, not a screenshot, in the tool result. Screenshots are a fallback when the tree is empty, and they should stay on the device.

MIT · community, economic, everyday

PythonRobotics

Upstream AtsushiSakai/PythonRobotics

One-file Python references for localization, SLAM, path planning, and obstacle avoidance. A textbook, not a vehicle stack.

A Grasshopper task can shell out to one example script for a local plan. The result is a path, not a subscription.

Do not: Do not put this code on a car. Do not wrap it in a paid API and strip the MIT notice.

  • Grasshopper — Register a task type local-python. The task record stores the script path, the inputs, and the stdout. Recovery replays the same command. No network in the task.
  • broccoli-core — Only if the phone image actually has the script. Otherwise the tick says the planner is not installed. Do not pretend.

Other agent stacks: Call the script as a tool with a working directory and a timeout. Return the path geometry. Keep the MIT copyright in the tool's about text.

Apache-2.0 · economic, everyday

agnocast

Upstream autowarefoundation/agnocast

ROS 2 middleware that moves large messages between processes without copying them. Includes a Linux kernel module. Apache-2.0.

Grasshopper tasks that move logs, images, or desktop frames should pass a path or an id. The model sees a description and a size, not the payload.

Do not: Do not load agnocast-kmod on a phone, a shared desktop, or a CI runner. Do not vendor the C++ into broccoli.

  • Grasshopper — Task inputs over a size limit become a resource id in the control plane. The executing environment opens the resource. The model is given the id and a one-line description.
  • helix — A desktop stream already should not be base64'd into an agent prompt. Keep the RFB session in the browser. The agent gets a screenshot only when a person asks for one frame.

Other agent stacks: Same rule on any runtime. Tool results carry ids. A separate local reader opens the bytes. This is how a person avoids paying a model to reread a log they already have on disk.

Apache-2.0 · community, everyday

auto_e2e

Upstream autowarefoundation/auto_e2e

Camera-only driving model from the Autoware Foundation. The public checkpoint can run without an HD map. It is not a phone app.

Grasshopper can record that shape of task (proposal, then veto) for any local model. The veto is the product. The network is not allowed to act alone.

Do not: Do not claim this checkpoint runs in Termux. Do not connect it to a vehicle from this account. Respect the checkpoint's own notice on the model card.

  • Grasshopper — Model a task state machine: proposed, accepted, rejected. Store who accepted. A model task that skips accepted is a failed task.

Other agent stacks: If you run your own camera model, publish the input size, the license, and the fact that a rule can override it. Do not hide the model behind a brand name.

Apache-2.0 · everyday, community

HoloAgent

Upstream HorizonRobotics/HoloAgent

An embodied-agent loop from Horizon Robotics: observe, retrieve, plan, act, verify, with a memory of the place. The project as a whole is Apache-2.0. Some bundled third-party SLAM pieces are not cleared for commercial use.

Grasshopper's tick already has execute and confirm. Add a verify step that checks the world, not the model's own claim of success. Broccoli's confirm step is the phone version of the same idea.

Do not: Do not import FAST-LIVO2 or HOVSG into a product. Their default licenses restrict commercial use. Do not download robot checkpoints into the phone repo.

  • Grasshopper — Name the task states observe, plan, act, verify. verify reads a local sensor or a test, not the model's summary of itself.
  • broccoli-core — After a tick changes a setting, read the setting back through the accessibility tree or a local API. That read is verify.

Other agent stacks: Publish the loop. Let another runtime implement verify however it can measure the world. Do not require their users to buy a particular robot.
